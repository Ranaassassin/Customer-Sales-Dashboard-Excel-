# Customer-Sales-Dashboard-Excel-

An interactive **Customer Sales Dashboard** built entirely in **Microsoft Excel** using **Power Query**, **Power Pivot**, **DAX Measures**, **Pivot Tables**, **Pivot Charts**, **Slicers**, and modern dashboard design techniques.

This dashboard transforms raw transactional data into meaningful business insights, enabling users to analyze customer behavior, profitability, and sales performance through an intuitive and interactive interface.

#  Project Overview

This project demonstrates how Microsoft Excel can be used as a Business Intelligence tool to build a fully interactive dashboard without requiring specialized BI software.

The dashboard provides an executive overview of customer performance by combining KPIs, interactive charts, geographic analysis, and dynamic filtering.

#  Business Objectives

- Monitor overall business performance.
- Track customer sales and profitability.
- Identify the most profitable customers.
- Discover the least profitable cities.
- Compare profit contribution across customer age groups.
- Analyze revenue by gender and marital status.
- Evaluate country-level gross profit.
- Enable interactive business reporting using slicers.

#  Business Questions Answered

The dashboard helps answer questions including:

- Which customers generate the highest gross profit?
- Which customer age group contributes the most profit?
- Which country contributes the highest gross profit?
- Which cities are the most profitable?
- Which cities generate the lowest profit?
- How does revenue differ by gender?
- How does revenue differ by marital status?
